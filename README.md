使用方法：1.复制文件到U盘并携带至机房。
         2.复制至桌面。
         3.运行ClassFreeGUI.exe，在输入框中输入等待时间。
         4.程序会隐藏，此时上课，老师控屏。
         5.倒计时结束，程序启动，杀死管控进程，重启桌面并弹出主菜单
         6.建议执行查杀守护进程和禁用驱动，以免管控进程复活。
         7.如未执行上述两个操作，软件会循环查杀管控进程，可能浪费较多系统资源，使本就不快的机房电脑雪上加霜。
